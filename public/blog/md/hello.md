# ブログはじめました

このサイトにブログ機能を追加しました。

## 書き方

- `public/blog/md/` に Markdown ファイルを置く
- ファイル名がURLになる（`hello.md` → `/Blog/hello/`）
- 先頭の `# 見出し` が記事タイトルになる
- 先頭に `tags: [タグ1, タグ2]` を書くとタグが付く（下記の形式）
- 投稿日・更新日は git のコミット日時から自動で入る

```
---
tags: [自転車, 日記]
---

# タイトル
```

| 機能 | 対応 |
| --- | --- |
| 表 (GFM) | ✅ |
| 画像 | ✅ |
| タグ | ✅ |
| コメント | ✅ (giscus) |
